How it works — Reactive does the watching

The vault cannot be woken by a server. It is woken by the network itself.

Sepolia

🎯 Vault

User deposits, any number of times. Every deposit emits a Deposited event carrying the running total and the target.

event
➜
Reactive Lasna

⚡ GoalReactive

Subscribed on-chain. Checks total ≥ target in ~1 second. Below target: silently does nothing. At target: fires once — one-shot guard.

callback
➜
Sepolia

🤝 Callback → Payout

GoalCallback authenticates the delivery twice, calls release(), and the beneficiary is paid. Goal completed — automatically.

✦ The target travels inside the event — a reactive contract cannot call Sepolia, so react() is fully self-contained. No oracle, no cross-chain reads, no cron job that could replace it.
